# MARS.NET: 산소실의 거짓말 / The Oxygen Room Lie

2050년, 민간 화성 이주가 정착된 시대의 익명 종합 커뮤니티 `MARS.NET`을 배경으로 한 3분 소셜 추리 채팅 게임입니다. 공휴일에 자유게시판의 `[초보 환영] 마피아 한 명 구함 (3/4)` 글을 발견한 플레이어는 서로 다른 구역에서 온 미나, 주노, 노엘과 게임을 시작합니다.

플레이어는 마피아가 되어 망가진 출입카드를 심고 자유 입력 거짓말로 투표를 움직입니다. 세 친구는 욕하거나 탈주하지 않지만, 각자의 기억·검증·관찰 방식으로 추리합니다. 우주복은 화성 주민이 외부 구역을 오갈 때 입는 일상 보호복입니다.

## 실행

프로젝트 루트에서 정적 파일·솔로 API 프록시·친구 모드 WebSocket을 함께 제공하는 ASGI 서버를 실행합니다.

```bash
scripts/serve
```

실시간 캐릭터 응답을 사용하려면 API 키를 파일에 저장하지 말고 실행할 셸에만 설정합니다.

```bash
OPENAI_API_KEY="your-key" scripts/serve
```

키체인에 프로젝트 키를 등록한 개발 환경에서는 다음 명령으로 실행할 수 있습니다.

```bash
scripts/serve-live
```

컴퓨터가 꺼지면 로컬 서버는 중단되지만 키는 사라지지 않습니다. 실제 공개 서비스에서는 호스팅 제공자의 비밀 저장소로 옮겨야 합니다.

- 기본 모델: `gpt-5.6-luna`
- 선택 변경: `OPENAI_MODEL="model-id" OPENAI_API_KEY="your-key" scripts/serve`
- 키가 없거나 API가 실패하면 규칙 기반 연습 응답으로 자동 전환되어 한 판을 끝까지 진행합니다.
- API 키는 브라우저로 전달되지 않고 로컬 서버의 `/api/chat`에서만 사용합니다.

보이스콜 모드는 일반 채팅과 별도 흐름으로 실행됩니다. 같은 서버의 `/api/realtime/client-secret`이 5분짜리 임시 시크릿만 발급하고, 브라우저가 그 시크릿으로 OpenAI Realtime WebRTC에 연결합니다. 플레이어 마이크는 `gpt-transcribe` 세션 하나에만 전송하며 OpenAI 서버 VAD가 버튼 없이 발화 시작과 침묵 종료를 감지해 전사 턴을 자동 확정합니다. `수동 말하기`와 `수동 입력 끝내기`는 자동 감지가 어려운 환경의 보조 수단이며, 무음·빈 자막은 듣기 상태로 복귀합니다. 미나·주노·노엘 음성은 말할 때만 `gpt-realtime-2.1-mini` 출력 세션을 하나씩 엽니다. 따라서 동시에 유지되는 세션은 최대 2개이며 영구 키와 원본 오디오는 브라우저 저장소에 남지 않습니다.

- 음성 출력 모델 변경: `OPENAI_REALTIME_MODEL`
- 음성 호출 실패·마이크 거절·권한 무응답 시 기존 텍스트 모드로 자동 전환
- 개발 비용 계측: localhost에서 `?voiceDebug=1`을 붙이면 키·대화 원문 없이 세션 수와 추정 비용만 콘솔에 표시

- 한국어: `http://127.0.0.1:4173/?lang=ko`
- English: `http://127.0.0.1:4173/?lang=en`
- 친구 모드: `http://127.0.0.1:4173/friend.html?lang=ko`

두 언어는 같은 게임 엔진을 사용하고 화면 문구만 `i18n.js`에서 관리합니다.
`scripts/serve`는 HTML을 캐시하지 않고 버전이 붙은 에셋만 장기 캐시해, 새로고침 때 구버전 화면이 남는 문제를 막습니다.

공개 테스트 배포는 `render.yaml`의 무료 Python Web Service를 사용합니다. `OPENAI_API_KEY`는 Blueprint 생성 화면에서 비밀 환경변수로만 입력하며 Git에는 저장하지 않습니다. 무료 인스턴스는 15분 동안 요청이 없으면 정지하므로 심사 제출 전에는 첫 접속 지연을 다시 검토합니다.

비회원 플레이는 계속 로컬에 저장됩니다. Supabase를 연결하면 Google PKCE 로그인 뒤 성장·판 기록·개인 채팅·프로필 이미지를 비공개 클라우드에 동기화할 수 있습니다. Apple 로그인은 공급자 설정이 완료될 때까지 UI에 노출하지 않습니다. 설정 절차는 [docs/SUPABASE_SETUP.md](./docs/SUPABASE_SETUP.md)를 따르며 서비스 역할 키는 서버 환경변수에만 둡니다. 계정 패널에서는 캐릭터별 채팅 삭제, 전체 JSON 내보내기, 로그아웃, 계정 삭제, 제작자 피드백 메일을 제공합니다.

테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

## 현재 범위

- Figma 레퍼런스를 바탕으로 한 390×844 모바일 우선 시작 → 모집글 튜토리얼 → 게임방 채팅 흐름
- 첫 방문에만 필수 사용자 이름과 선택 프로필 사진을 브라우저에 저장하는 온보딩
- 튜토리얼에서 게임방 입장과 미나·주노·노엘 개인 채팅으로 바로 이동
- 사건 1개: 화성 거주구역 산소실, 22:10 화성 표준시, 공기 정화기 안전장치 고장
- 망가진 출입카드, 조종실 카메라 알리바이, 산소실 공구, 시간 진술 모순
- 승무원 3명, 가짜 증거 1개, 회의 1라운드
- 매 판 위치가 달라지는 사실 카드 3개
- 자유 입력 채팅 2턴: 지목 1회 + 반박 답변 1회
- 텍스트 또는 AI 보이스콜 선택, 확정 음성 자막만 기존 구조화 판정과 게임 엔진에 연결
- 실제 오디오 이벤트와 동기화된 단일 화자 큐, 실시간 자막, 마이크 음소거, AI 음성 일시정지, 끼어들기, 재연결, 텍스트 폴백
- 이모티콘 선택기를 포함한 1:1 친구 채팅
- 비회원 즉시 플레이와 첫 판 종료 후 Google 로그인 저장 안내
- revision·mutation ID를 이용한 Supabase 클라우드 동기화, 오프라인 변경 대기열, 게스트 기록 병합
- 최근 개인 채팅 50개 우선 로드와 커서 기반 이전 기록 불러오기
- 캐릭터별 채팅 삭제, 전체 기록 JSON 내보내기, 최근 재인증이 필요한 계정 영구 삭제
- `su.jin.lee.developer@gmail.com`으로 보내는 제작자 피드백·문의 진입점
- 두 실제 플레이어와 정착민 캐릭터 2명이 참여하는 비공개 친구 게임방
- 6자리 초대 코드, 세션 토큰 재연결, 60초 연결 복구, 30분 비활성 만료
- 인간 채팅을 먼저 전파한 뒤 캐릭터 2명이 순차 답변하며, 검증된 지목·주장·모순이 서버 의심 상태에 반영되는 구조
- 일반 친구 모드 메시지 1개당 모델 호출 3회(의미 판정 1회 + 캐릭터 답변 2회), 장애 시 호출 0회의 로컬 대체 응답
- 문장 길이와 캐릭터에 따라 `입력 중` 시간이 달라지고 한 명씩 도착하는 순차 메시지
- 사건·사실 배치·이전 대화를 함께 전달해 판마다 달라지는 실시간 캐릭터 응답
- 직전 판의 실제 선택·투표·결과만 회상하는 경기 후 세 친구 대화
- 개인 채팅 뒤 제안되는 캐릭터별 다음 판 서브퀘스트와 성공 +3·실패 +1 친밀도

- 5번째 단서에서 해금되는 사립탐정: 한 명의 현재 의심 방향을 보는 대신 그 인물을 직접 공격할 수 없음
- 추천 문장은 전송 선택지가 아니라 수정 가능한 입력 초안
- 증거 심기부터 투표 직전까지 한 게임방에서 이어지는 모바일 메신저형 흐름
- 공개 단서 보관함, 캐릭터 말풍선, 하단 고정 입력창과 연결 강도 라벨
- Luna 구조화 판정 1회 + 캐릭터별 격리된 응답 3회(턴당)
- 키 부재·API 장애 시 결정론적 연습 응답
- 승무원별 개별 의심, 투표 이유, 승패, 다시 하기
- 단서 2개가 연결될 때 강한 의심으로 판정
- 거짓말 전 판단과 최종 판단 비교
- 실제 표 변화에 따른 1★~3★ 승리 등급
- 미나 Lv.2·주노 Lv.4·노엘 Lv.3에서 시작해 판마다 성장하는 1~50 레벨과 10레벨 단위 추리 난이도
- 저장 레벨은 유지하면서 해당 판의 AI를 +20레벨로 계산하는 선택형 하드 모드

- 공격 화면의 세 사실 요약과 주장-사실 연결 표시

- 한국어·영어 전환
- 4종의 선택형 서브퀘스트

- M3 역할 기반 색상과 HIG 터치·safe area 원칙을 결합한 화면 체계
- 자동·라이트·다크 3단계 테마 선택과 사용자 설정 저장
- Figma Chat AI Bot 레퍼런스의 보라색 역할 체계와 모바일 메신저 계층을 재해석한 화면
- 첫 사용자 동작 뒤 자동 재생되는 대기실·게임 Pixabay 배경음, 기본 음량 30%, 음소거·음량 저장
- 메시지·증거·결과·단서 획득에만 쓰이는 짧은 상황 애니메이션과 동작 줄이기 지원
- 그라데이션·글로우·glassmorphism·반짝이 없이 목록 중심으로 구성한 커뮤니티 디자인
- 친구별 기본 게시글 5개와 접속한 서로 다른 날짜마다 추가되는 익명글 1개
- 게시글 사진·짧은 영상·MARS.NET 반응 이모티콘, 댓글 입력 중 표시와 지연 답글

미나는 팬덤 게시판 특유의 빠르고 감정적인 말투로 기록과 캡처를 기억하고, 주노는 개발·기술 게시판처럼 사실과 추측 및 반례를 나누며, 노엘은 인터넷 방송 게시판처럼 말투와 반응 변화를 포착합니다. 캐릭터 대화에서는 화성 생활을 필요할 때만 자연스럽게 언급하며 모델·프롬프트 같은 메타 발언을 하지 않습니다.

사실·의심 점수·투표·승패는 규칙 기반 엔진이 결정하고, 모델은 플레이어 문장의 구조화와 캐릭터 대화만 담당합니다. 이 분리로 대사는 매번 달라져도 결과 규칙은 재현 가능합니다. 브라우저 코드에는 API 키를 넣지 않습니다.
