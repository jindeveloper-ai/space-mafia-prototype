# 산소실의 거짓말 / The Oxygen Room Lie — v0.5.0

플레이어가 마피아가 되어 승무원 한 명에게 가짜 증거를 심고, 매 판 달라지는 세 가지 사실을 이용해 거짓말한 뒤 AI 승무원 세 명의 투표를 조종하는 3분짜리 브라우저 게임입니다.

## 실행

프로젝트 루트에서 정적 파일 서버를 실행합니다.

```bash
python3 -m http.server 4173
```

- 한국어: `http://127.0.0.1:4173/?lang=ko`
- English: `http://127.0.0.1:4173/?lang=en`

두 언어는 같은 게임 엔진을 사용하고 화면 문구만 `i18n.js`에서 관리합니다.

테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

## 현재 범위

- 사건 1개
- 고정 사건 기준: 산소실, 22:10
- 승무원 3명
- 가짜 증거 1개
- 회의 1라운드
- 매 판 위치가 달라지는 사실 카드 3개
- 공격 대상 3명 × 주장 방식 3종
- AI 반박 1회 × 플레이어 답변 3종
- 승무원별 개별 의심, 투표 이유, 승패, 다시 하기
- 단서 2개가 연결될 때 강한 의심으로 판정
- 거짓말 전 판단과 최종 판단 비교
- 실제 표 변화에 따른 1★~3★ 승리 등급
- 공격 화면의 세 사실 요약과 주장-사실 연결 표시
- 알리바이·장소 단서·시간 모순 안내
- 한국어·영어 전환

현재 승무원 반응은 실제 생성형 AI가 아닌 규칙 기반 `MOCK AI`입니다. 하나의 전역 의심 점수 대신 승무원마다 별도의 판단 점수와 이유를 가지며, 단서 하나나 분위기만으로 몰표하지 않도록 서로 다른 단서의 연결을 우선합니다. 핵심 루프가 재미있는지 확인한 다음 서버를 추가해 OpenAI API를 연결합니다. 브라우저 코드에는 API 키를 넣지 않습니다.
