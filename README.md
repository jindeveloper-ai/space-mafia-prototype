# 산소실의 거짓말 / The Oxygen Room Lie — v0.7.2

익명 커뮤니티에서 만난 개성 있는 세 친구와 부담 없이 즐기는 3분짜리 소셜 추리 브라우저 게임입니다. 플레이어는 마피아가 되어 가짜 증거와 매 판 달라지는 사실을 이용해 투표를 움직입니다.

## 실행

프로젝트 루트에서 정적 파일 서버를 실행합니다.

```bash
scripts/serve
```

- 한국어: `http://127.0.0.1:4173/?lang=ko`
- English: `http://127.0.0.1:4173/?lang=en`

두 언어는 같은 게임 엔진을 사용하고 화면 문구만 `i18n.js`에서 관리합니다.
`scripts/serve`는 HTML을 캐시하지 않고 버전이 붙은 에셋만 장기 캐시해, 새로고침 때 구버전 화면이 남는 문제를 막습니다.

테스트는 다음 명령으로 실행합니다.

```bash
npm test
```

## 현재 범위

- 사건 1개
- 고정 사건 기준: 산소실, 22:10
- 승무원 3명
- 가짜 증거 1개
- 회의 1라운드
- 매 판 위치가 달라지는 사실 카드 3개
- 공격 대상 3명 × 주장 방식 3종
- AI 반박 1회 × 플레이어 답변 3종
- 승무원별 개별 의심, 투표 이유, 승패, 다시 하기
- 단서 2개가 연결될 때 강한 의심으로 판정
- 거짓말 전 판단과 최종 판단 비교
- 실제 표 변화에 따른 1★~3★ 승리 등급
- 공격 화면의 세 사실 요약과 주장-사실 연결 표시
- 알리바이·장소 단서·시간 모순 안내
- 한국어·영어 전환
- 4종의 선택형 서브퀘스트
- 320px부터 데스크톱까지 대응하는 모바일 우선 커뮤니티 UI
- 기기의 라이트·다크 모드를 자동으로 따르는 HIG 색상 체계

현재 친구들의 반응은 실제 생성형 AI가 아닌 규칙 기반 엔진입니다. 하나의 전역 의심 점수 대신 인물마다 별도의 판단 점수와 이유를 가지며, 성격에 따라 기록·가정·반응을 다르게 봅니다. 핵심 루프가 재미있는지 확인한 다음 서버를 추가해 OpenAI API를 연결합니다. 브라우저 코드에는 API 키를 넣지 않습니다.
