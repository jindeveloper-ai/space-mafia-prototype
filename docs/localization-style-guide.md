# MARS.NET 번역 스타일 가이드와 용어집

## 적용 범위

지원 코드는 `ko`, `en`, `ja`, `zh-CN`, `zh-TW`, `yue-Hant-HK`, `es-419`로 고정한다.
언어팩은 게임, 친구방, 계정, 오류, 접근성 문구를 같은 버전으로 제공한다.

## 공통 원칙

- 버튼은 명사보다 짧은 동사를 우선한다. 같은 행동은 모든 화면에서 같은 용어를 쓴다.
- 원문의 단어 순서보다 화면의 목적, 단서의 논리 관계, 화자의 감정을 우선한다.
- `사실`, `추측`, `반례`, `알리바이`, `모순`은 서로 바꾸어 쓰지 않는다.
- 캐릭터 이름은 음역하고, 브랜드 `MARS.NET`과 방 번호 `#041`은 번역하지 않는다.
- 중국어 간체와 번체는 별도 지역 표현을 쓴다. 광둥어는 표준중국어 문장에 조사만 바꾸는 방식으로 만들지 않는다.
- 개인정보처리방침과 이용약관의 권위본은 기존 언어로 유지한다. 새 언어의 법률 문구는 법률 검수 전까지 참고 번역으로 표시한다.
- 원어민 승인은 출시 필수 조건이 아니다. 승인받지 않은 번역을 원어민 검수 완료로 표시하지 않는다.

## 캐릭터 말투

| 캐릭터 | 변하지 않는 성격 | 피해야 할 말투 |
| --- | --- | --- |
| Mina | 빠르고 감정적이다. 캡처, 시간, 팬 커뮤니티 반응을 바로 언급한다. | 차분한 기술 보고서, 증거 없이 공격적인 단정 |
| Juno | 사실과 가설을 분리하고 반례를 요구한다. 짧고 분석적이다. | 과도한 전문용어, 밈 위주의 반응 |
| Noel | 말투와 반응 순서의 변화를 먼저 본다. 짧게 핵심을 찌른다. | 장문의 장비 설명, 기록만 반복하는 말투 |

언어별 기준:

- `ko`: 온라인 친구 채팅처럼 자연스럽게 쓰되 비속어와 과도한 초성체를 피한다.
- `en`: 중립적인 국제 영어를 쓰고 캐릭터 대사에서만 가벼운 인터넷 말투를 허용한다.
- `ja`: 버튼은 간결한 보통체, 설명은 정중체를 기본으로 한다. 캐릭터 대사는 과장된 역할어보다 현대적인 온라인 대화를 쓴다.
- `zh-CN`: 중국 본토 UI 용어와 간결한 보통화 문장을 쓴다.
- `zh-TW`: 대만 UI 용어인 `個人檔案`, `置物櫃`, `感測器`, `快取`를 고정한다.
- `yue-Hant-HK`: 홍콩 번체와 자연스러운 구어체 `嘅`, `喺`, `冇`, `邊個`, `傾偈`, `而家`를 쓴다. Juno의 분석 문장은 다른 캐릭터보다 문어적인 표현을 일부 유지할 수 있다.
- `es-419`: 특정 국가의 은어와 스페인식 `vosotros`를 피하고, 중남미 전역에서 이해하기 쉬운 `ustedes` 기준의 중립 문체를 쓴다.

## 금지 패턴

- 간체 팩에 일본어 가나 또는 한국어 문구를 섞지 않는다.
- 번체 팩에 간체 전용 글리프를 남기지 않는다.
- `zh-TW`에 광둥어 구어 조사 `嘅`, `喺`, `冇`를 쓰지 않는다.
- `yue-Hant-HK`를 표준중국어 문장만으로 구성하지 않는다.
- `es-419`에 스페인식 `vosotros`, `coger` 중심 표현이나 특정 국가만 통하는 UI 은어를 쓰지 않는다.
- 번역 함수가 `undefined`를 반환하거나 `__PLACEHOLDER__` 같은 작업용 표식을 노출하지 않는다.

## 검수 순서와 증거

1. 문맥 번역: 화면 목적, 단서 관계, 캐릭터 말투를 함께 번역한다.
2. 별도 모델 비평: 의미 누락, 부자연스러운 말투, 지역 부적합 표현을 목록으로 남긴다.
3. 역번역 의미 비교: 승패 조건, 개인정보 고지, 오류 복구 행동의 의미가 보존되는지 확인한다.
4. 용어·호칭·말투 검사: 이 문서의 용어집과 캐릭터 기준을 대조한다.
5. UI 길이 검사: 자동 길이 제한을 통과한 뒤 모바일과 데스크톱에서 시각 검수한다.

`scripts/check-language-packs.mjs`는 구조, 함수 반환 형태, 문자 체계 누출, 핵심 용어,
광둥어 표지, 짧은 UI 길이를 자동 검사한다. 모델 비평과 역번역은 자동 검사를 대체하지
않으며, 출시 후보마다 검토자와 결과를 별도 기록한다.
